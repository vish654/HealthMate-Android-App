# HealthMate Android Wellness App

## Project Overview

HealthMate is an Android wellness application developed using Kotlin and Android Studio.

The app helps users maintain healthy daily routines through habit tracking, mood journaling, hydration reminders, and mood trend visualization.

## Features

- Daily Habit Tracker
- Add, edit, delete and complete habits
- Mood Journal with emoji selection
- Hydration Reminder using AlarmManager
- Local data storage using SharedPreferences
- Mood trend chart using MPAndroidChart
- Clean and responsive mobile UI

## Technologies Used

- Kotlin
- Android Studio
- SharedPreferences
- AlarmManager
- MPAndroidChart
- XML Layouts
